# 问题

如何防止 Agent 长期记忆被错误信息污染？

# 回答

不应让模型把每段对话自动写成长期事实。写入前先分类：用户明确偏好、经验证的业务事实、任务中间状态和模型推断应该分开存储，其中推断不得冒充事实。

每条记忆应携带所属用户/租户、来源、创建时间、有效期、置信度、版本和可退回的原始证据。敏感或高影响记忆需要用户确认；来自网页、邮件、工具或其他 Agent 的内容按不可信数据处理，先验证再写入。

读取时按身份和命名空间隔离，同时返回来源和时效性。系统还需要冲突合并、过期、用户更正/删除、审计和异常写入告警机制。

# 面试考察点

能否将记忆当作有来源、权限和生命周期的数据，而不是可无限追加的向量库。
