# 问题

针对工具调用进行微调时，训练数据和评测应如何设计？

# 回答

数据不能只包含“用户问题→正确工具”的简单正例。每个样本应保留当时可见的工具定义、对话/状态、目标工具与精确参数，必要时包含工具结果和后续动作。

数据集要包含：不应调用任何工具的负例；高度相似工具的难例；缺少必要参数时先追问的样本；权限不足、风险过高和需审批时的拒绝/中断样本；工具失败、重试和停止；以及真实参数的长尾分布。去除密钥和个人信息，防止近重样本跨训练/测试集泄漏。

评测分开统计工具选择、不调用决策、参数字段/整体精确匹配、Schema 有效率、权限与审批合规、轨迹成功率、延迟和 token 成本。按工具对和业务场景切片，并与未微调基线在同一固定集上对比。

# 面试考察点

是否覆盖了不调用、追问、拒绝、失败恢复和近似工具，而非只优化简单正例。
