# 问题

如何为 Agent 建立一套离线与在线评测体系？

# 回答

先把业务目标拆成可观测指标：任务完成率、约束违反率、事实/引用正确性、工具选择与参数正确率、高风险动作拦截率、延迟、token/工具成本和人工接管率。

离线集合来自真实任务的去敏样本、高频流程、历史失败、边界情况和对抗样本，并按任务类型分层。确定性约束用代码断言，语义质量可用人工标注或经校准的 LLM 评委。每次提示词、模型、工具或编排变更都跑回归。

在线阶段先 shadow/canary，再逐步放量；监控真实成功信号、用户更正、重试、升级人工、安全事件和分位延迟/成本。将经审核的线上失败回流到离线集，防止只优化初始基准。

# 面试考察点

是否能建立“线下回归—小流量验证—线上失败回流”的闭环。
