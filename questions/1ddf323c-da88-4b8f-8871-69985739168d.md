# 问题

长时间运行的 Agent 如何实现中断恢复？

# 回答

需要把 Agent 从“一个长函数”设计成可持久化的状态机或工作流。在关键步骤后原子地保存检查点：任务输入、当前节点、已完成步骤、待处理动作、工具结果引用、版本和幂等键。大文件存在对象存储中，状态只保存内容寻址标识。

恢复时从最后一个已确认的检查点继续，而不是重放整段对话。有副作用的节点必须幂等，并能处理“下游已执行、本地未记录成功”的不确定状态，通过查询幂等键或对账确定结果。

状态 Schema、prompt、模型和工具都要记录版本，为运行中升级提供迁移或继续使用旧版的策略。超时、取消、人工审批和租约过期也应是可持久化状态。

# 面试考察点

是否理解检查点、副作用幂等和版本恢复是一套整体设计。
