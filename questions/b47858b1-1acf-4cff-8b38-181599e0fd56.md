# 问题

如何对可调用外部系统的 Agent 实施最小权限？

# 回答

最小权限不是在 prompt 中说“不要越权”，而是由模型之外的系统强制执行。首先只向当前任务暴露所需工具，优先只读或约束式 API，不提供任意 shell、SQL、HTTP 请求等宽泛能力。

其次，以当前用户和任务身份获取短期、限定受众和 scope 的凭据，不把平台管理员密钥交给 Agent。工具后端对每次调用执行对象级授权，不信任模型传入的 `user_id`、`tenant_id` 或“已获授权”声明。

最后限制可写对象、金额、数量、速率、时间窗口和出站目标；高风险行为需人工审批；所有授权、代理链和执行结果必须可审计和可撤销。

# 面试考察点

是否会将工具集、凭据、对象级授权和影响半径都纳入最小权限。
