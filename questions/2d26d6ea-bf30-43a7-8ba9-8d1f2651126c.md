# 问题

工具调用的参数校验、重试和幂等性应如何设计？

# 回答

先分清三层责任。模型输出层用 JSON Schema 或类型模型校验形状；工具适配层校验格式、范围和业务前置条件；下游服务仍要独立鉴权和保证不变式。校验失败时只把可修正的字段级错误返给 Agent。

只对短暂性错误重试，如超时、429 或可恢复的 5xx；对参数错误、权限拒绝和业务冲突不做盲目重试。重试使用指数退避与抖动，有最大次数和总时限。

对会改变外部状态的调用，由系统为一次逻辑操作生成幂等键，重试必须复用同一键。服务端持久化“幂等键→执行状态/结果”，并处理“请求已成功但响应丢失”的不确定结果。

# 面试考察点

能否区分可重试性和幂等性，并覆盖响应丢失这个典型分布式系统边界。
