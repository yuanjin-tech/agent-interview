# 问题

子 Agent 之间应共享全部上下文还是相互隔离？

# 回答

默认不应共享全部上下文。每个子 Agent 只应得到完成子任务所需的目标、输入、约束、可用工具和输出 Schema。这能减少 token 消耗、无关信息干扰、敏感数据泄露和间接提示注入的传播。

隔离也不意味着什么都不共享。可共享的是经过结构化、裁剪和标注来源的任务状态，例如子目标、产物 URI、证据和状态码；不应默认转发所有私有提示、凭据和原始对话。

为每个 Agent 设置独立的权限、内存/文件命名空间和日志身份。共享状态需要版本号、所有者、合并规则与冲突检测，避免多 Agent 并发覆盖。

# 面试考察点

是否会按最少必要信息和最小权限设计子 Agent 边界。
