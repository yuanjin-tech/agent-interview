# 问题

一个 Agent 工作流中应如何为不同节点选择模型？

# 回答

不应用同一个“最强模型”承担所有节点，也不应先为了省钱就选最小模型。先用较强模型建立可接受的质量基线，再根据节点的需求逐个替换并回归。

选型维度包括：推理难度，工具调用和结构化输出遵循率，上下文长度，多模态需求，延迟和吞吐，单价，数据驻留/合规，稳定性与版本支持。简单分类、路由、抽取可用小模型或代码；模糊规划、多步综合和高风险判断倾向更强模型。

用真实输入按节点评测，不只看总任务分数。运行时可根据任务复杂度或小模型置信度升级到强模型，但路由规则也要测试、监控和设置成本上限。

# 面试考察点

是否能用节点级评测在质量、延迟、成本和合规之间做取舍。
