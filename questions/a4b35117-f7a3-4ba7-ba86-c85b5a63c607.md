# 问题

MCP 中的 Prompts、Resources 和 Tools 有什么区别？

# 回答

它们的核心区别是“提供什么”以及“谁决定使用”：

- **Prompts** 是 Server 提供的参数化消息或交互模板，通常由用户主动选择，例如“审查这个 PR”。
- **Resources** 是可通过 URI 识别的数据或内容，通常由应用决定如何浏览、读取和加入上下文，例如文件内容、数据库 Schema 或 Git 历史。
- **Tools** 是可执行的函数，可查询数据或产生副作用，通常由模型在任务中选择调用。

“谁决定”是产品交互层的默认控制模型，不是安全保证。Host 仍然需要展示同意、约束权限，Server 仍然需要验证调用。不要用只读 Resource 冒充会改变状态的 Tool，也不要在 Prompt 中隐藏用户无法看到的高风险行为。

# 面试考察点

能否区分模板、上下文数据和可执行能力。
