# 问题

Agent 的提示词、模型和工具升级应如何发布与回滚？

# 回答

把 prompt、模型 ID 及参数、工具 Schema/实现、编排图和记忆策略当作同一个可版本化的 Agent 发布单元。每次 run 记录完整版本组合，否则线上退化时无法重现。

发布流程是：Schema 和单元测试→固定 Agent 回归集→安全对抗集→影子流量→少量 canary→逐步放量。通过功能开关或版本路由保留旧版，用任务成功率、约束违反、工具错误、延迟和成本设置自动停止条件。

回滚不只是换回旧 prompt。要考虑运行中任务、新旧状态 Schema、已产生的副作用和长期记忆。对不兼容的长任务，可以锁定旧版继续、显式迁移或安全终止，不应在中途静默切换。

# 面试考察点

是否把 Agent 的所有行为依赖一起版本化，并处理运行中状态。
