# 问题

如何降低 Agent 的响应延迟和模型成本？

# 回答

先用 trace 分解端到端时间和成本：排队、模型首 token/生成、工具网络、检索、重试、序列化和人工等待，并按 p50/p95/p99 与任务类型观察。只看平均值或单次 token 价格容易优化错地方。

优化顺序通常是：删除不必要的 Agent 轮次和重复工具调用；缩小历史、检索结果和动态工具 Schema；对不依赖的查询并行执行；缓存稳定、授权安全且有版本键的结果；让路由、分类、格式化等简单节点使用小模型或确定性代码；对用户尽早流式返回可用进度。

每个优化都在固定评测集上校验任务成功率和安全指标，避免用降低正确率换取表面上的快和便宜。

# 面试考察点

是否先用分段观测定位，再同时看质量、延迟和成本。
