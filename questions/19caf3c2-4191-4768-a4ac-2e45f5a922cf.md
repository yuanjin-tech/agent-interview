# 问题

为什么评估 Agent 不能只看最终答案？

# 回答

同一个正确答案可能来自完全不同的轨迹：一个 Agent 查询了正确资料并核验，另一个可能凭猜测命中；一个只读，另一个可能做了多余的写操作。只看答案会漏掉偶然正确、过度授权、无效重试和高成本路径。

应分三层评估：

- **最终结果**：任务是否完成，内容和引用是否正确。
- **轨迹**：工具选择、顺序、参数、重试、审批与终止是否合理。对允许多条正确路径的任务，不要硬性要求唯一顺序。
- **单步**：对关键路由、工具参数或安全决策单独测试，快速定位退化。

再配合延迟、调用次数和成本，才能判断 Agent 是否“稳定地用正确方式完成”。
