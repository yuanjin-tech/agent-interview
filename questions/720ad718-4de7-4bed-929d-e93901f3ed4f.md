# 问题

什么是 Agent，它与普通 LLM 应用有什么区别？

# 回答

Agent 是一个由模型参与决定工作流执行过程，并能通过工具感知环境或改变外部状态的系统。典型运行链是：接收目标→选择下一步行动→调用工具→观察结果→调整策略，直到完成、失败或转交人类。

普通 LLM 应用可能只做一次“输入→生成”，或由程序预先写死每个步骤。关键区别不是是否使用了 LLM，而是模型是否在边界内自主决定下一步及工具使用。

生产级 Agent 仍然是普通软件系统：模型负责模糊判断，程序负责权限、参数校验、超时、重试、审批、审计和终止条件。

# 面试考察点

是否能从“自主控制流+工具+反馈循环”界定 Agent，而不是把所有聊天机器人都称为 Agent。
