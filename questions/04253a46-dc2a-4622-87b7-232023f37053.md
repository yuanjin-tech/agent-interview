# 问题

使用 LLM-as-a-Judge 评测 Agent 有哪些风险，如何降低偏差？

# 回答

风险包括：评委对长度、表达风格、答案位置或自己熟悉的模型有偏好；评分不稳定；无法核验隐藏事实；被候选输出中的注入文本操纵；评委与被测 Agent 共享相同错误。

降低风险的方法是：用明确且尽量可观测的评分 rubric，一次只评一个维度；提供参考答案和必要证据；对成对比较随机交换顺序；固定模型版本和推理配置；使用结构化输出并重复采样检查一致性。

最重要的是与人工金标做盲测校准，按任务类型计算一致性，并定期复审误判样本。可以用代码断言的 Schema、权限、数值和工具轨迹不要交给 LLM 评委。

# 面试考察点

是否把 LLM 评委当作需要校准的测量工具，而非绝对真值。
