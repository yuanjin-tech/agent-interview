# 问题

多 Agent 系统中 Manager 模式与 Handoff 模式有什么区别？

# 回答

Manager 模式由一个中央 Agent 持有用户交互和总任务责任，将专业 Agent 当作工具调用，最后由 Manager 汇总。它适合需要统一口径、跨领域综合和中心化管控的场景，但 Manager 可能成为上下文、性能和决策瓶颈。

Handoff 模式把当前对话的控制权转给另一个 Agent，后者可直接继续与用户交互。它适合职责和交接边界清晰的服务台或部门路由，但容易出现误转、循环转交和上下文丢失。

设计时要明确：转交的是“一个子任务”还是“整个对话控制权”，传递哪些状态，权限是否变化，以及谁负责终止和回收。

# 面试考察点

候选人能否说清“调用子能力”与“转移控制权”的区别。
