# 问题

如何防范检索内容中的间接提示注入？

# 回答

检索到的网页、邮件和文档是不可信数据，即使它们看起来像“系统指令”也不能提升权限。仅靠在 prompt 中写“忽略恶意指令”不足以形成安全边界。

需要分层防御：

- 将指令与检索数据在消息结构和标记上明确分离，只允许从数据中提取任务所需事实。
- 在采集和检索阶段做来源信任、权限、内容类型和异常模式过滤，但不把检测器当成绝对保证。
- 读取不可信内容的 Agent 不应同时拥有高风险写工具；使用最小权限、域名/参数白名单、沙箱、出站限制和人工审批缩小影响面。
- 对“正常用户任务+恶意外部内容”的组合场景做红队和回归评测，同时检测未授权工具尝试。

# 面试考察点

是否理解根因是高信任指令与低信任数据被模型共同解释，并用权限边界限制破坏性。
