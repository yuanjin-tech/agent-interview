# 问题

Agent 系统中的密钥、个人信息和日志应如何保护？

# 回答

密钥由密钥管理系统保存和注入工具执行环境，不放进 system prompt、模型上下文、代码库或工具描述。优先使用短期、最小 scope、绑定受众的凭据，定期轮换，并防止出现在错误返回和调试输出中。

对个人信息先做数据盘点和目的限制：只收集任务必需字段，在进入模型、记忆、轨迹和评测集前按需脱敏或令牌化；按用户/租户隔离，加密传输与存储，设置保留期和删除通道。

日志需要可调试，但不等于原样记录每个 prompt 和工具结果。记录 trace/run 关联、模型/工具版本、决策类型、时延、成本和脱敏后错误；敏感轨迹使用更严格的访问控制、审计和短保留期。

# 面试考察点

是否能平衡可观测性与数据最小化，并让密钥始终留在模型上下文之外。
