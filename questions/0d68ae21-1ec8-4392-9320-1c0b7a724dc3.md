# 问题

Agent 的运行循环应如何设计和终止？

# 回答

一个基本循环包含“构造当前上下文、请求模型、解析最终回答或工具调用、执行工具、写入观察结果”。每轮都应记录状态和轨迹，不能只依赖模型自觉停止。

终止条件至少包括：产生符合 Schema 的最终输出、达成可程序验证的任务目标、需要人工输入、遇到不可恢复错误，以及触发最大轮数、总超时、token 预算或工具费用上限。

还应检测停滞：连续几轮没有新信息、重复同一工具和参数、在两个状态间往返等。触发后可先给模型一次结构化的纠错信息，仍无法恢复则停止并返回已完成步骤、失败原因和可继续的检查点。

# 面试考察点

是否将终止视为运行时的确定性责任，并同时考虑正常完成、安全上限和停滞检测。
