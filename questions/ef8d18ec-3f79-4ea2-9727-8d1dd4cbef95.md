# 问题

多 Agent 对同一任务产生冲突结论时应如何处理？

# 回答

先不要用多数投票直接当作真值。多个 Agent 可能共享同一模型、数据和错误假设，它们的错误并不独立。应要求每个 Agent 输出结构化结论、证据引用、未确定性和可验证主张。

裁决顺序是：先用确定性检查器或原始权威数据验证；再让裁决器对比证据而非只看结论；能补充证据时发起有目标的二次查询；无法消解或为高影响决策时，把差异、证据和待决问题交给人类。

工程上还要保存各结论的来源和版本，避免裁决器覆盖原始结果。在评测中单独统计冲突率、裁决正确率、少数正确意见被压制的比例和额外成本。

# 面试考察点

是否会优先验证证据，并识别多 Agent 错误相关性。
