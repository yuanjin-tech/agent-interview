# 问题

Agent 陷入无限循环或工具震荡时应如何排查？

# 回答

先从轨迹中找到最小重复模式：是同一工具和参数重复，两个工具往返，规划反复重置，还是工具结果没有正确写入状态。对每轮比较目标、可用工具、模型输出、工具返回和状态差异。

常见原因包括：没有明确完成信号；工具成功返回不可机读；错误信息不能指导修正；工具描述重叠；历史被截断导致忘记已执行动作；每轮从旧检查点恢复；或指令同时要求“必须调用”和“必须等待”。

修复时增加结构化状态与完成条件，对工具结果去重，检测相同调用或状态哈希，设置最大步数/时间/成本上限。触发限制时返回可诊断的停止原因或升级人工，不是静默截断。

# 面试考察点

能否用轨迹和状态差异定位循环，并用确定性上限兜底。
