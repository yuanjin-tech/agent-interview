# 问题

什么情况应该使用 Agent，什么情况更适合确定性工作流？

# 回答

当任务存在大量非结构化输入、例外多、需要语义判断，而且下一步无法事先枚举时，Agent 有价值。例如调研、客诉分析、复杂故障诊断。

当流程规则稳定、输入结构化、每个分支可枚举，或对确定性、审计和延迟要求极高时，应优先使用代码、规则引擎或状态机。例如计税、额度检查、固定审批链。

实际系统通常是混合的：用 Agent 理解意图、补齐信息和选择路径，用确定性程序执行权限检查、金额计算和不可逆操作。选型前应问：不确定性带来的业务价值，是否超过它带来的成本、测试和风险。

# 面试考察点

是否能抵制“什么都用 Agent”，并根据业务不确定性和风险进行选型。
