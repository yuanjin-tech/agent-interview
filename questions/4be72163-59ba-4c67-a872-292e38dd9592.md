# 问题

Agent 的哪些操作应该设置人工审批？

# 回答

应根据影响而不是工具名称评级。需优先审批的包括：不可逆或难以撤销的写操作；付款、大额退款、删除和生产发布；对外发送邮件/消息；扩大数据或系统权限；涉及法律、医疗、金融等高风险判断；以及 Agent 低置信、连续失败或任务目标发生变化的情况。

审批点要放在副作用发生前。界面展示具体工具、完整关键参数、数据来源、预计影响、可逆性和费用，允许“批准、编辑后批准、拒绝并反馈”。审批人和执行人的身份要写入审计记录。

低风险只读操作可自动执行；高频写操作可通过预先授权的金额、对象和时间边界降低审批疲劳，超出边界再中断。

# 面试考察点

是否会用影响、可逆性、权限和置信度决定审批，并把审批放在执行前。
