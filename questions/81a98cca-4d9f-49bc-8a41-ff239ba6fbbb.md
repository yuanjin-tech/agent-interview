# 问题

ReAct 与 Plan-and-Execute 架构各有什么优缺点？

# 回答

ReAct 把推理和行动交替进行：模型根据当前观察选一个动作，执行后再决定下一步。它适合信息不完全、需要边探索边修正的任务，但可能短视、重复调用工具，长任务中成本较高。

Plan-and-Execute 先生成计划，再逐步执行，必要时重新规划。它更适合依赖关系清晰、可并行、需要进度可见的长任务；缺点是初始计划可能建立在错误假设上，过度规划也会增加延迟。

较好的实现通常是混合模式：先产生粗粒度、可修订的计划，执行每个子目标时使用 ReAct；设置重规划触发条件，而不是每一步都重做全局计划。

# 面试考察点

能否围绕反馈频率、全局性、可恢复性和成本做权衡，而不只背诵流程图。
