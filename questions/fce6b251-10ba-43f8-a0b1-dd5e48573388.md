# 问题

RAG Agent 的检索召回率较低时应如何排查？

# 回答

先建立包含问题、应命中文档和应答信息的小型标注集，分层检查：

1. **语料层**：正确内容是否被采集、解析、去重和更新，权限过滤是否误删。
2. **切分层**：块大小和重叠是否破坏标题、表格、代码与上下文关系，元数据是否完整。
3. **查询层**：Agent 是否选对检索器，改写是否丢掉关键实体、时间和范围。
4. **召回层**：比较稠密、BM25 和混合检索，检查 embedding 模型、语言、top-k、过滤条件和索引版本。
5. **重排层**：候选中有正确文档但最终被排除，说明问题在 reranker 或截断。

使用 Recall@k、MRR 等指标按查询类型切片，每次只修改一个因素。不要用扩大 top-k 掩盖语料或查询问题，因为它会把噪声和成本传递给后续生成。

# 面试考察点

能否将采集、切分、路由、召回和重排分层定位。
