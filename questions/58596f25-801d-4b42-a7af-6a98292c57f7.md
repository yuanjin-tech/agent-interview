# 问题

SKILL 和 MCP 的区别

# 回答

它们最本质的区别可以用一句话概括：**MCP 告诉模型“谁来做”，Skill 告诉模型“怎么做”。**

| 维度                 | Skill | MCP                        |
| -------------------- | ----- | -------------------------- |
| 上下文消耗（未命中） | 低    | 高（可通过渐进式披露缓解） |
| 上下文消耗（命中）   | 高    | 低                         |
| 接入成本             | 低    | 高                         |
| 可扩展性             | 高    | 低                         |
| 贡献人群             | 广    | 窄                         |
| 确定性               | 低    | 高                         |
| 对通用工具的依赖     | 高    | 低                         |
| 越权风险             | 高    | 低                         |

在使用场景上，**MCP 负责提供底层工具能力，Skill 负责编排上层业务流程。**，也就是说，用 MCP 提供“能力”，用 Skill 规定“用法”

- **适合 MCP 的功能**：文件读写、命令执行、网络搜索、接口调用、代码执行等**流程复杂同时对确定性、安全性要求高**的操作。
- **适合 Skill 的功能**：机票怎么订、行程怎么规划、退货怎么退、怎么介绍产品、怎么成交等**对灵活性、专业性要求高**的流程。
