# 问题

Skill 和 MCP 的区别是什么？

# 回答

Skill 和 MCP 不在同一抽象层，也不是二选一的替代关系。

- **Skill** 通常是供 Agent 按需加载的专业知识、操作规程和配套资源，重点是告诉 Agent “在某类任务中应该怎么做”。它可以引导 Agent 使用已有工具，但自身不必然提供远程调用协议。
- **MCP** 是应用与外部能力之间的通信协议，定义 Host、Client、Server 以及 Tools、Resources、Prompts 等原语如何发现和交互，重点是“能力如何被标准化地暴露和调用”。

两者可以组合：例如一个“退货处理 Skill”规定核验订单、判断政策和确认退款的流程，其中通过 MCP Server 提供的订单查询和退款工具执行真实操作。

需要注意，“Skill”在不同产品中的定义可能不同，因此面试时应先说明自己采用的产品语境，不应把两者的上下文消耗、安全性或扩展性简化成普适高低判断。

# 面试考察点

候选人是否能区分“流程知识”与“能力接入协议”，并理解两者可以协同使用。
