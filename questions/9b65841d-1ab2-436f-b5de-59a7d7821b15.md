# 问题

MCP 的 Host、Client 和 Server 分别负责什么？

# 回答

- **Host** 是用户直接使用的 AI 应用。它创建和管理 Client，集成模型，决定连接和用户授权，并负责跨 Server 的上下文隔离与安全策略。
- **Client** 是 Host 内与某一个 Server 保持会话的协议组件。它完成初始化、能力协商、消息路由、通知和订阅管理。一个 Client 对应一个 Server 连接。
- **Server** 是独立提供上下文和能力的程序，暴露 Tools、Resources 和 Prompts，可通过本地 stdio 或远程 HTTP 连接。

安全责任不能都推给 Server：Host 控制用户同意、上下文聚合和连接边界，Server 则必须校验自己收到的身份、权限和参数。能力协商只表示“支持某功能”，不等于对具体操作已授权。

# 面试考察点

是否能清晰说明应用管理、单连接协议处理和能力提供三层责任。
