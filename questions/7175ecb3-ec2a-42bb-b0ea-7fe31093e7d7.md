# 问题

直接提示注入和间接提示注入有什么区别？

# 回答

直接提示注入是攻击者在自己能控制的用户输入中放入恶意指令，例如要求忽略系统约束或泄露内部信息。间接提示注入则隐藏在 Agent 为完成正常任务而读取的网页、邮件、文档、工具返回值或其他 Agent 消息中。

后者更难发现，因为用户请求本身可能完全正常，恶意内容是运行中才被加载的。它还可能通过记忆写入或 Agent 间转发产生持久和级联影响。

两者的防护都不能只靠提示词。需要分离指令与不可信数据，限制工具权限和参数，对高风险动作进行确定性校验和人工审批，监控异常工具轨迹，并用组合攻击场景做回归评测。

# 面试考察点

能否从攻击内容的来源和信任边界区分两者。
